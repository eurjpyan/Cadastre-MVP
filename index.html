Connecter votre projet Supabase
À faire une seule fois pour que vos données soient hébergées en ligne.
  1. Créez un projet gratuit sur supabase.com
  2. Ouvrez SQL Editor et exécutez le script fourni sous ce dashboard
  3. Allez dans Project Settings → API
  4. Copiez Project URL et anon public key ci-dessous
Cette clé publique est prévue pour être utilisée côté navigateur — la sécurité réelle vient des règles RLS définies par le script SQL.
La configuration est enregistrée de manière sécurisée dans votre stockage local.
